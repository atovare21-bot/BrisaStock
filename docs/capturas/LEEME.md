# Imágenes de apoyo

Los archivos SVG de esta carpeta son ilustraciones vectoriales de las pantallas de inicio de sesión y del panel. Se construyeron a partir de la estructura HTML y los estilos del proyecto para orientar la lectura del manual.

No son capturas de pantalla de una ejecución real: los nombres, cifras y estados son ficticios. Para documentar una instalación concreta, reemplázalas por capturas tomadas después de iniciar sesión con datos de demostración y oculta cualquier información personal o comercial.
